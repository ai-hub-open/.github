# Как внести вклад

Спасибо, что хотите доработать инструменты. Каждое принятое исправление экономит время всем, кто ими работает, а ваше имя остаётся в истории изменений и в авторах.

Вклад кодом не обязателен: скиллы — это методология, написанная по-русски. Разбор ошибки агента с примером, уточнение инструкции в SKILL.md, пример из вашей практики — полноценный вклад, и часто более ценный, чем правка кода.

## Что принимаем

- Исправления ошибок и уточнения документации.
- Поддержку новых полей и операций API площадок — со ссылкой на официальную документацию площадки.
- Улучшения правил безопасности (черновики, подтверждения, журнал) — это ядро проекта, такие правки проверяем внимательнее всего.
- Новые скиллы и мосты — сначала откройте Issue с предложением, чтобы не делать работу впустую: обсудим, впишется ли инструмент в организацию. Организация не ограничивается рекламными площадками: принимаем инструменты под любые задачи маркетолога и бизнеса, которые агент может взять на себя.

## Что не принимаем

- Правки, ослабляющие правила безопасности: снятие черновиков и пауз, включение удаления объектов, запись без подтверждения. Такие PR мы закрываем и объясняем почему.
- Возможности, которых нет в API площадки, и описания, обещающие больше, чем делает код: мы сверяем документацию с кодом.

## Порядок

1. Форкните репозиторий, создайте ветку от `main`.
2. Внесите изменения. Документация — по-русски; названия инструментов и полей API — как в оригинале площадки.
3. Если изменили возможности инструмента — обновите README, включая раздел об ограничениях.
4. Подпишите коммиты (DCO, см. ниже) и откройте Pull Request по шаблону.

## DCO — подпись вклада

Мы используем Developer Certificate of Origin: строка `Signed-off-by: Имя <email>` в каждом коммите подтверждает, что у вас есть право передать этот код под лицензией репозитория (Apache-2.0). Подпись добавляется командой:

```
git commit -s
```

Отдельных договоров подписывать не нужно.

## Имена новых репозиториев

Скилл называется по роли агента (`marketing-strategist`), мост — по площадке с суффиксом `-mcp` (`yandex-direct-mcp`).
