# AI-hub — открытые инструменты для агентного маркетинга

Инструменты для маркетологов и бизнеса: с ними ИИ-агент может управлять рекламными кампаниями на российских площадках — Яндекс Директе и VK Рекламе. Агент у вас уже есть (Claude, Cursor или другой). Здесь лежит то, что превращает его из собеседника в исполнителя: **скиллы** — наборы инструкций, по которым агент ведёт работу как специалист, — и **MCP**, через которые агент напрямую работает с API площадок.

Сегодня инструменты закрывают работу с рекламными кабинетами. Фокус организации шире — любые задачи маркетолога и бизнеса, которые агент может взять на себя: стратегия, запуск, ведение, отчётность. Набор инструментов будет расти.

Инструментов для агентного маркетинга много, но большинство сделано под западные площадки, а поддержка Директа и VK в них поверхностная: в API VK «кампания» означает не то, что кампания в кабинете, у Директа свои лимиты и обязательный автотаргетинг — на таких деталях чужие инструменты ошибаются. Инструменты, опубликованные здесь, сделаны под российские кабинеты изначально: ловушки API учтены, поля и форматы — реальные, структура кампании создаётся целиком и в правильном порядке — без групп и объявлений, которые созданы через API, но не видны в кабинете.

Всё открыто (лицензия Apache-2.0), бесплатно, работает по-русски — и останется таким.

## Инструменты

| Репозиторий | Что это |
|---|---|
| [marketing-strategist](https://github.com/ai-hub-open/marketing-strategist) | Скилл-стратег: от брифа до документа со стратегией — аудитория, конкуренты, площадки, бюджет по фазам |
| [yandex-direct-manager](https://github.com/ai-hub-open/yandex-direct-manager) | Скилл для Яндекс Директа: семантика из Вордстата, минус-слова, объявления, кампания черновиком в кабинете |
| [vk-ads-manager](https://github.com/ai-hub-open/vk-ads-manager) | Скилл для VK Рекламы: матрица аудиторий, креативы с ревью, кампания на паузе |
| [yandex-direct-mcp](https://github.com/ai-hub-open/yandex-direct-mcp) | MCP к API Яндекс Директа: кампании, группы, объявления, ставки, отчёты — из вашего агента |
| [vk-ads-mcp](https://github.com/ai-hub-open/vk-ads-mcp) | MCP к API VK Рекламы: сборка структур, аудитории, бюджеты, статистика |

Скиллы и MCP работают вместе и по отдельности: скилл ведёт процесс, мост даёт доступ к кабинету.

Скиллы здесь — не сборники промптов «напиши объявление», каких много в каталогах. Каждый ведёт процесс целиком: семантика собирается из Вордстата, а не выдумывается моделью; подбираются минус-слова, кампании проходят кросс-минусацию; каждый заголовок укладывается в лимит площадки. На узловых решениях агент останавливается и спрашивает вас.

## Безопасность по умолчанию

Обычно безопасность связки «агент + рекламный API» держится на аккуратности модели. Мы исповедуем другой подход: ошибка в кабинете стоит живых денег, поэтому безопасность поддерживается сразу на нескольких уровнях:

- **Скиллы ведут процесс так, чтобы ошибиться было трудно:** кампании собираются черновиком или на паузе, запуск подтверждает маркетолог; перед записью в кабинет агент показывает план и ждёт «ОК»; удаление в процессах скиллов не используется — удаляет только человек.
- **MCP дают агенту полный доступ к рекламной платформе** — все операции API, включая удаление; это написано в README каждого моста, ничего не спрятано. Поэтому рекомендуемый способ работы — скилл вместе с мостом: скилл держит дисциплину, мост исполняет.
- **Ключи под контролем:** реквизиты доступа не попадают в рабочие файлы, доступ агента к рекламным кабинетам можно отозвать; у MCP в прямом режиме есть песочница — весь цикл создания кампании можно прогнать без живого бюджета.

## Подключение к кабинетам

Основной путь — через агентские кабинеты [click.ru](https://click.ru). Причина практическая. Прямой доступ к API площадки — многошаговая процедура: регистрация своего приложения, заявка на доступ, одобрение площадкой, цепочка OAuth-согласий. Через click.ru мост подключается токеном — без заявок и ожидания. Плюс рекламные обороты через click.ru возвращаются кэшбеком.

Прямое подключение своим ключом (без click.ru) тоже поддерживается в обоих MCP — если доступ к API у вас уже есть или вы хотите его получить.

## С чего начать

1. Выберите инструмент: нужна стратегия — берите скилл стратега; запускаете кампанию в Яндекс Директе — вам нужен скилл вместе с MCP Директа.
2. Откройте README репозитория — там установка с нуля, без опыта в агентной среде.
3. Первую проверку сделайте на своём брифе, до подключения кабинета: увидите, как агент работает, не потратив ни рубля.

Последний довод при выборе любого инструмента из каталога: документация здесь сверяется с кодом, и границы названы честно — не только что инструмент умеет, но и чего от него ждать не стоит. Выбирайте по ограничениям, а не по маркетинговым обещаниям — это правило мы применяем к себе первыми.

Самое ценное в этих инструментах — не код, а методология профи от маркетинга: как опытный директолог чистит запросы, как таргетолог собирает аудиторию, которую не стыдно показать клиенту, так наши скиллы делают вашу рутину. Это не написано ни в справке рекламных площадок, ни в учебниках — это живёт в головах практиков. Агентный маркетинг в России только складывается, и каким он будет — решают те, кто вкладывает свой опыт в открытые инструменты сейчас.

Здесь рады вкладу без кода: скиллы написаны по-русски, и разбор ошибки агента, пример из вашей практики или правка методологии — уже вклад. Пробуйте инструменты на своих задачах, приносите в Issues то, чего не хватает, дорабатывайте что умеете. Как оформить предложение — описано CONTRIBUTING.
